# ADR-001: Project Platform

## Status

Accepted

## Context

The goal is to build a production-grade DevOps platform using modern open-source technologies and AWS cloud services.

## Decision

The platform will use:

- Debian 12
- Docker
- Kubernetes (k3s)
- Terraform
- Jenkins
- GitHub Actions
- ArgoCD
- Prometheus
- Grafana
- Loki

## Consequences

The project closely resembles modern production environments while remaining lightweight enough for a single lab server.
